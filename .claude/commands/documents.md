# documents

Run `npm run docs`, or `npm run docs -- estate-accounts` for one kind, or `npm run docs -- estate-accounts <id-prefix>` for one estate. Files land in `docs-out/`. Change the business name, colours and logo in `brand.json`. These are working documents for the adviser to check and sign off; nothing is sent.
