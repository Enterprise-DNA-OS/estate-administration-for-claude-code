# insights

Answer the ten questions in the README from the records in one run.

Run `node scripts/estates.mjs insights`. Add `--json` when you need every field. Resolve the estate, beneficiary or asset by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

Summarise each answer in one line, then show the rows that matter.
