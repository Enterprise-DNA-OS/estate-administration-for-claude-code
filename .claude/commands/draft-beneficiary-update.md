# draft-beneficiary-update

Draft an update for beneficiaries: money collected, paid, distributed and held, what is left to collect and when distribution can happen.

Run `node scripts/estates.mjs draft-beneficiary-update <ref>`. Add `--json` when you need every field. Resolve the estate, beneficiary or asset by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

Read /history first. Replace the next-step line with the real next task. Nothing is sent.
