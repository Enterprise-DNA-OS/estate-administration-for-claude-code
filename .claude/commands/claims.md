# claims

List claims and written notices of intention to claim, with the date an NZ notice lapses.

Run `node scripts/estates.mjs claims`. Add `--json` when you need every field. Resolve the estate, beneficiary or asset by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

Live claims hold distribution. Say when each lapses and what would keep it alive (filing or service).
