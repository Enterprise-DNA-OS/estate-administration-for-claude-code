# history

Show one estate in full: window, money, beneficiaries, assets, debts, claims and recent activity.

Run `node scripts/estates.mjs history <ref or name>`. Add `--json` when you need every field. Resolve the estate, beneficiary or asset by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

Read this before drafting or changing anything on the estate.
