# weekly-review

Write the Monday review from attention, windows and money held.

Run `node scripts/estates.mjs weekly-review`. Add `--json` when you need every field. Resolve the estate, beneficiary or asset by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

Summarise in five lines: what is overdue, what lapses this week, what can be distributed, who owns each. The full draft is in drafts/.
